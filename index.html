СПРАВКА
MetroFlow — учебная интерактивная модель анализа пассажиропотока Московского метрополитена.

Координаты и названия станций загружаются из OpenStreetMap с помощью Overpass API.

Показатели пассажиропотока являются расчётными оценками, а не официальной статистикой Московского метрополитена.

Формула модели:
Y = 0.15P + 0.25J + 1500A + 5000T

P — население района;
J — рабочие места;
A — точки притяжения;
T — количество пересадок.
